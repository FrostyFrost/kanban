# Канбан → PWA (iOS / iPadOS / Android / любой Safari)

Папка `kanban-pwa/` содержит готовый комплект PWA:

```
kanban-pwa/
├── index.html            — оригинальный index.html + PWA-матаги
├── manifest.json         — манифест PWA
├── icons/                — иконки (192, 512, apple-touch-icon, favicon)
├── app.js                — без изменений
└── styles.css            — без изменений
```

## Что потребуется

- GitHub репозиторий `FrostyFrost/kanban` (UI) — публичный (для Cloudflare Pages / GitHub Pages)
- Репозиторий `FrostyFrost/kanban-data` — приватный (данные задачи)
- Apple-аккаунт / телефон, работающий только в Safari
- GitHub Personal Access Token (PAT) с scope `repo` — для записи/чтения приватного репо данных

## Шаг 1. Залить PWA-приложение в публичный репо `kanban`

Сделайте на своей машине:

```bash
cd /path/to/kanban                 # локальная копия репо UI
cp /workspace/kanban-pwa/index.html /workspace/kanban-pwa/manifest.json .
cp -r /workspace/kanban-pwa/icons .
git add index.html manifest.json icons/
git commit -m "feat(kanban): add PWA manifest + icons for iOS Add-to-Home-Screen"
git push
```

Замечание: если вы заказал PWA-папку в `/workspace/kanban-pwa/` — скопируйте её в свой локальный репозиторий. README и DEPLOY.md можете не трогать.

## Шаг 2. Включить GitHub Pages в репо UI

Это даёт HTTPS-URL вида `https://<ваш-юзер>.github.io/kanban/`.

1. Откройте https://github.com/FrostyFrost/kanban
2. **Settings → Pages**
3. Источник: **Deploy from a branch**
4. Branch: `main`, папка `/ (root)` → **Save**
5. Подождите ~1 минуту, обновите страницу — статус «Your site is live at ...» (`https://frostyfrost.github.io/kanban/`)

При отсутствии Pages (репо приватный — Pages работать не будет):

Если репозиторий `kanban` оказался приватным, либо Pages недоступны — создайте
**отдельный публичный репозиторий** `kanban-ui` (или `kanban-app`) для UI — Pages
работает только для публичных репо. Данные при этом останутся в приватном `kanban-data`.

Если Pages не срабатывает:
- проверьте branch/папку в настройках Pages,
- проверьте, что `manifest.json` и `icons/` действительно попали в ветку `main`,
- очистите кэш браузера (⌘⇧R в Safari).

## Шаг 3. Открыть приложение на iPhone

1. Откройте Safari → https://frostyfrost.github.io/kanban/
2. Дождитесь загрузки доски.
3. В нижнем меню → **Поделиться** → **На экран Домой** → подключите
   «На экран Домой» → имя «Канбан» → **Добавить**.
4. На домашнем экране появится значок «Канбан» — приложение открывается в
   полноэкранном режиме, как нативное.

## Шаг 4. Настроить синхронизацию с приватным репо данных

1. В приложении нажмите **⚙** (шестерёнка в шапке).
2. В поле **GitHub PAT** введите новый PAT (scope `repo`, 90 дней):
   - https://github.com/settings/tokens → **Generate new token (classic)**
   - Scope: **`repo`**
   - Скопируйте токен (показывается один раз).
3. В поле **Репозиторий данных** проверьте: `FrostyFrost/kanban-data`.
4. Поле **Файл**: `tasks.jsonl`, **Ветка**: `main`.
5. **Сохранить**.
6. Нажмите **☁⇄** — приложение подтянет данные из приватного репо (через GitHub API
   с вашим токеном) и попросит отредактировать/сохранить. Если pull прошёл без ошибок —
   всё готово.

Важно:
- Токен хранится **только в localStorage Safari на вашем устройстве**. Никогда не
  вставляйте его в чат, не коммитьте в git, не отправляйте куда-либо.
- Чтобы отключить синхронизацию — в ⚙ нажмите **Сбросить токен**.
- Если токен сдох/протух — создайте новый PAT тем же способом и вставьте в ⚙.

## Что работает / не работает в PWA на iOS

Уже готово и покрыто кодом:
- ✅ доска (4 колонки, drag&drop карточек)
- ✅ календарь с метками и повторяющимися задачами
- ✅ создание/редактирование/удаление задач
- ✅ синхронизация pull + push через GitHub (API для приватного репо)
- ✅ PWA: значок на домашнем экране, полноэкранный режим

Не работает на iOS (ограничения iOS/Safari):
- ❌ автосохранение в локальный файл (File System Access API — только Chromium) —
  замените ☁⇄ на pull + push в репозиторий данных
- ❌ выбор файла вручную (📁) — не работает; данные берутся только через ☁⇄
- ❌ offline-режим (PWA кэширует только статику; данные — только через GitHub API)
- ❌ уведомления — iOS поддерживает только через нативное приложение

## Если нужно: позже — нативный iOS-бандл

Когда появится Mac с Xcode и нужен настоящий нативный UI (без зависимостей от

с `WKWebView`. Это отдельная задача; текущий PWA не ломает путь к ней.
