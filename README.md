# Канбан

Локальная интерактивная доска задач с календарём и JSONL-файлом, пригодным для синхронизации через GitHub.

## Что внутри

```
.
├── index.html    — интерфейс (доска + календарь)
├── styles.css    — стили
├── app.js        — логика (drag&drop, CRUD, календарь, синхронизация)
└── README.md     — этот файл
```

## Как пользоваться

1. Откройте `index.html` в браузере (Chrome/Edge — лучше всего, есть File System Access API).
2. Первый раз выберите файл `tasks.jsonl` (кнопка 📁). Браузер запомнит handle в IndexedDB и будет переиспользовать его между сессиями.
   - **Всегда подтверждайте первый раз вручную через 📁.** Без выбора файл не будет перезаписан: изменения только локально (localStorage).
   - После перемещения карточки, скрытия, создания/удаления — страница автоматически перезаписывает `tasks.jsonl`. Если файл не привязан, страница покажет предупреждение «Файл не привязан».
3. По кнопке **☁** синхронизируйте изменения:
   - если в настройках (⚙) задан GitHub PAT — страница зальёт файл в репозиторий данных через GitHub API;
   - если токен не задан — файл скачается, и останется сделать коммит/push вручную в терминале.
4. Возврат из-под GitHub — кнопка 🔄 (или при открытии страницы) подгружает актуальное состояние из репозитория данных.

## Формат задач (`tasks.jsonl`)

Один JSON-объект — на одну строку. Пример:

```json
{"id":"a1b2c3","text":"Купить молоко","status":"todo","due":"2026-11-28","tags":["family"],"notes":"","created":"2026-11-26","updated":"2026-11-26T18:00:00.000Z"}
```

Поля:

- `id` — уникальный идентификатор
- `text` — название
- `status` — `todo` (надо сделать) / `doing` (в работе) / `waiting` (ожидание) / `done` (выполнено)
- `due` — дата дедлайна `YYYY-MM-DD` или пустая строка
- `tags` — список строк, напр. `["work","family","school"]`; стандартные теги: `work`, `family`, `school`, `other` — остальные — пользовательские
- `notes` — заметка (необязательно)
- `hidden` — `true`/`false` — скрыта ли карточка (сгорает только кнопкой «Показать скрытые» в шапке)
- `recur` — необязательно, повторение: `{ "every": 1, "unit": "day"|"week"|"month"|"year", "until": "YYYY-MM-DD"|"" }`. При завершении задачи автоматически создаётся следующая инстанция со сдвинутым дедлайном на интервал. Пустое `until` — без ограничения
- `created` — дата создания (`YYYY-MM-DD`)
- `updated` — дата/время последнего изменения (ISO)

Файл можно редактировать вручную или через AI-агента. Невалидные строки будут пропущены (в консоли браузера будет «Пропущено невалидных строк: N»).

## Синхронизация

**Дерево репозиториев:**

- `kanban` — UI (этот репозиторий)
- `kanban-data` — данные (`tasks.jsonl`)

**Синхронизация на одном компьютере:**

1. Откройте `index.html`
2. Нажмите ☁ — страница зальёт `tasks.jsonl` в репозиторий данных через GitHub API
3. Другой компьютер: откройте `index.html` → кнопка 🔄 подтянет изменения

**Вручную (без PAT):** в ⚙ задайте репозиторий, затем скачайте файл (кнопка ☁ без токена) и сделайте коммит/push в терминале:

```bash
git add tasks.jsonl
git commit -m "sync from kanban"
git push
```

## Совместимость

- Chrome / Edge: File System Access API (автосохранение) полностью
- Firefox: без автосохранения, кнопка 📁 открывает файл, fallback — скачивание/загрузка
- Safari: как Firefox

## Keyboard shortcuts

- `N` — новая задача
- `S` — синхронизация с GitHub
- `Esc` — закрыть модалку

## Повторяющиеся задачи

В модалке задачи есть чекбокс «Повторять». При включении задаются:
- **интервал** (1–99),
- **единица** (дни / недели / месяца / года),
- **до** (необязательно — дата окончания повторения).

Дедлайн обязателен для повторяющихся задач. Карточка всегда остаётся одна — в календаре метки повторяются по датам, на которые попадает задание, включая будущие даты (по последним заданным значениям).

**Завершение повторяющейся карточки.** При переносе карточки в колонку «Выполнено» (drag&drop или форма) система спрашивает: выполнить весь цикл или только одно событие?
- **Весь цикл** → метки исчезают из календаря, у карточки снимается `recur`, она остаётся в «Выполнено».
- **Только одно событие** → карточка возвращается в «Надо сделать» с новой датой — следующей датой цикла после текущей. Одна метка с календаря (текущая дата) исчезает, остальные продолжают показываться.
- **Отмена** → ничего не меняется.

**Завершённые карточки** скрыты с календаря (включая повторяющиеся, хотя метки и исчезли из календаря). Если карточку перетаскивают обратно в рабочие этапы, она возвращается на календарь. Hidden-карточки (скрытые через 👁) также исключаются из календаря независимо от статуса.
